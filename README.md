# Releases

LOH AIO Archive가 배포하는 앱을 내려받는 곳입니다. 각 릴리스에는 앱 zip 파일과, 내려받은 파일이 손상되지 않았는지 확인할 때 쓰는 SHA-256 파일이 함께 올라와 있습니다. zip 파일을 내려받아 문서, 바탕 화면, 다운로드처럼 평소 파일을 저장하는 폴더에 압축을 풀고 앱을 실행하세요. 앱은 사용자가 업데이트 확인을 누를 때만 이 저장소에 접속합니다.

릴리스 이름은 `<앱>-v<버전>` 형식입니다(예: `bundle-viewer-v1.0.0`). 아래 앱별 사용 안내는 각 앱의 최신 릴리스에 들어 있는 안내와 같습니다.

## LOH Bundle Viewer

PC에 있는 Unity 번들 파일을 열어 캐릭터의 3D 모델과 모션을 미리 보는 Windows 앱입니다. 번들 파일은 앱에 포함되어 있지 않으므로 직접 준비해야 합니다.
