# LOH Bundle Viewer

PC에 있는 Unity 번들 파일을 열어 캐릭터의 3D 모델과 모션을 미리 보는 Windows 앱입니다. 번들 파일은 앱에 포함되어 있지 않으므로 직접 준비해야 합니다.

## 필요한 환경

- Windows 10 또는 Windows 11(64비트)
- Microsoft Edge WebView2 런타임(앱 화면을 표시하는 데 쓰는 Windows 구성 요소): 대부분의 Windows 10/11에 이미 설치되어 있습니다. 없으면 앱을 실행할 때 안내 창이 뜹니다. 이때는 [Microsoft 다운로드 페이지](https://developer.microsoft.com/microsoft-edge/webview2/)(영문 페이지)에서 "Evergreen Standalone Installer"의 x64 버전을 받아 설치한 뒤 앱을 다시 실행하세요.

Python이나 Node.js 같은 다른 프로그램은 설치하지 않아도 됩니다.

## 설치와 실행

1. [릴리스 페이지](https://github.com/avillon-archive/releases/releases)에서 `LOHBundleViewer-Windows.zip`을 내려받습니다.
2. zip 파일을 마우스 오른쪽 버튼으로 클릭하고 "압축 풀기"를 선택해 압축을 풉니다. 문서, 바탕 화면, 다운로드처럼 평소 파일을 저장하는 폴더에 푸세요. `C:\Program Files`처럼 프로그램이 설치되는 폴더에 풀면 앱 안에서 업데이트를 설치할 수 없습니다.
3. 압축을 푼 `LOHBundleViewer-Windows` 폴더에서 `LOHBundleViewer.exe`를 실행합니다. 같은 폴더의 `_internal` 폴더와 `release.json` 파일은 실행에 필요하므로 지우거나 옮기지 마세요.

## 번들 파일 준비

번들 파일이 들어 있는 폴더를 그대로 여는 것이 가장 간단합니다. 파일을 골라 다른 폴더로 옮기면 재질, 텍스처, 뼈대 정보가 든 번들이 빠져서 캐릭터가 제대로 보이지 않을 수 있습니다.

공용 번들 `shader_common`과 `defaulttexture`는 항상 열려는 번들과 같은 폴더에 있어야 합니다. 그 밖에 캐릭터마다 필요한 번들이 폴더에 없으면 창 아래쪽 상태 표시줄에 "의존 번들 N개가 폴더에 없습니다."가 표시되고, "로그 보기"에서 빠진 파일 이름을 확인할 수 있습니다.

## 사용하기

1. 창 위쪽의 "폴더 열기"로 번들 폴더를 열면 폴더 안의 캐릭터가 모두 목록에 나타나고, "파일 열기"로 번들 파일을 고르면 그 캐릭터의 번들만 나타납니다. 폴더나 파일을 창에 끌어다 놓아도 됩니다.
2. 왼쪽 "에셋" 목록에서 분류를 펼치고, 볼 묶음에 체크한 뒤 "선택한 묶음 불러오기"를 누릅니다. 묶음은 같은 캐릭터의 번들 파일들을 하나로 묶은 단위입니다. 공용 번들은 목록에 나타나지 않는 것이 정상입니다.
3. 불러온 묶음 아래에 나타나는 prefab(캐릭터 모델) 중 하나를 고르면, 앱이 번들을 화면에 표시할 수 있는 형태로 변환해 가운데 화면에 캐릭터를 표시합니다.
4. 위쪽 "모션"에서 동작을 골라 재생합니다.

캐릭터가 열리지 않거나 이상하게 보이면 가운데 화면 위쪽의 "로그" 탭에서 이유를 확인하세요. 빠진 번들, 지원하지 않는 재질, 변환 실패가 기록됩니다. 로그에 이유가 없는데 캐릭터가 이상하게 보이면 설정 화면의 "캐시 삭제"로 저장된 변환 결과를 지운 뒤 다시 열어 보세요.

현재 버전에서는 다음을 지원하지 않습니다.

- 배경(맵)
- 연출: 스킬 등의 모션은 재생하지만, 연출용 카메라와 이펙트는 적용하지 않습니다.
- 소리(오디오)

## 업데이트

창 오른쪽 위의 설정 버튼을 누르고 "업데이트 확인"을 누르면 새 버전이 있는지 확인합니다. 앱은 이 버튼을 누를 때만 인터넷에 접속합니다.

새 버전이 있으면 "설치 후 재시작"을 누르세요. 앱이 새 버전을 내려받아 파일을 바꾼 뒤 자동으로 다시 실행됩니다. 업데이트해도 설정과 저장된 변환 결과는 그대로 남습니다. 업데이트에 실패하면 원래 버전으로 다시 실행되고 상태 표시줄에 실패가 표시됩니다.

업데이트에 실패했거나 앱을 `C:\Program Files` 같은 폴더에 풀어 앱 안에서 업데이트할 수 없다면, [릴리스 페이지](https://github.com/avillon-archive/releases/releases)에서 새 zip 파일을 내려받아 다시 압축을 푸세요.

## 저장되는 파일

앱은 설정, 로그, 변환 결과를 `%LOCALAPPDATA%\loh-bundle-viewer` 폴더에 저장합니다. 이 경로를 그대로 파일 탐색기 주소창에 붙여 넣고 Enter 키를 누르면 폴더가 열립니다.

- `cache`: 같은 캐릭터를 다음에 빠르게 열 수 있도록 저장한 변환 결과
- `viewer.log`: "로그" 탭에 나오는 내용과 같은 기록
- `runtime.log`: 앱이 시작되지 않을 때의 오류 기록

로그는 일정 크기를 넘으면 오래된 내용부터 지워집니다. 변환 결과를 저장할지와 최대 용량은 설정 화면의 "변환 캐시"에서 바꾸고, "캐시 삭제"로 지울 수 있습니다.

## 앱 지우기

압축을 푼 `LOHBundleViewer-Windows` 폴더와 `%LOCALAPPDATA%\loh-bundle-viewer` 폴더를 삭제하면 됩니다.
